# Bulletbar

A minimalist task toolbar for Obsidian, inspired by Bullet Journal.

A minimalist toolbar for managing task status, priority, and list structure.

## Features

* Task status: ⚪️ Todo · 🐌 Later · 🔄 Doing · ✅ Done · ❌ Cancel
* Priority: 🔴 High priority
* Multi-line actions
* Automatic status detection
* Desktop: list toggle, indent & outdent

Task format:

```text
Status -> Priority -> Task
```

`🔴` can be combined with any status.

## Usage

### Desktop

A toolbar appears above the editor with task status, priority, list, indent, and outdent controls.

### Mobile & Tablet

A dedicated toolbar provides the six task actions.

* Phone: symbols only
* Tablet: symbols + text

Use **Toggle Bulletbar** from the Obsidian command palette to show or hide the mobile toolbar.

## Installation

### Community Plugins

1. **Settings → Community plugins → Browse**
2. Search **Bulletbar**
3. Install and enable

### Manual

Copy the plugin files to:

```text
<Vault>/.obsidian/plugins/bulletlist-toolbar/
```

Then enable **Bulletbar** in **Settings → Community plugins**.

# Bulletbar

一个受 Bullet Journal 启发的 Obsidian 极简任务工具栏。

用于快速管理任务状态、优先级和列表结构。

## 功能

* 任务状态：⚪️ 待开始 · 🐌 推迟 · 🔄 进行中 · ✅ 完成 · ❌ 取消
* 优先级：🔴 高优先级
* 支持多行操作
* 自动识别当前状态
* 桌面端：列表切换、缩进和减少缩进

任务格式：

```text
状态 -> 优先级 -> 任务内容
```

`🔴` 可以与任意状态组合。

## 使用

### 桌面端

编辑器上方显示工具栏，提供任务状态、优先级、列表、缩进和减少缩进操作。

### 手机和平板

提供独立的 6 个任务操作。

* 手机：只显示 Emoji
* 平板：显示 Emoji + 文字

可在 Obsidian 命令面板中使用 **Toggle Bulletbar** 显示或隐藏移动端工具栏。

## 安装

### 社区插件

1. **设置 → 第三方插件 → 浏览**
2. 搜索 **Bulletbar**
3. 安装并启用

### 手动安装

将插件文件复制到：

```text
<Vault>/.obsidian/plugins/bulletlist-toolbar/
```

然后在 **设置 → 第三方插件** 中启用 **Bulletbar**。
