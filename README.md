# Bulletlist Toolbar

一个 Obsidian 插件，用于给子弹清单快速添加状态和优先级标记。

## 功能

- 为当前子弹清单项添加待办、进行中、完成、取消、延后状态
- 一键切换高优先级标记
- 在编辑模式中显示紧凑工具栏

## 使用示例

在 Obsidian 的 Markdown 编辑模式中，先写一个普通子弹清单：

```markdown
- 整理项目文档
- 跟进插件发布
- 检查本周任务
```

把光标放到某一行后，点击工具栏按钮即可添加状态或优先级：

```markdown
- 🔄 🔴 整理项目文档
- ✅ 跟进插件发布
- ○ 检查本周任务
```

也可以通过命令面板执行对应命令，例如“标记当前行为完成”或“切换高优先级”。
